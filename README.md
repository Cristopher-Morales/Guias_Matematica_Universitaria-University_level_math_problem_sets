# Guías de Matemática Universitaria  
# University-Level Mathematics Problem Sets

This repository contains **university-level mathematics problem sets** covering a wide range of topics. The material was compiled during my undergraduate studies and has since been **typeset in LaTeX** for clarity, consistency, and ease of use.

⚠️ **Authorship notice**  
The exercises included in this repository are **not original**. They were collected from problem sets and examinations from several Chilean universities and are shared here **strictly for educational purposes**.

The primary goal of this repository is to provide **well-organised, LaTeX-formatted practice material** for students studying mathematics at the university level.

---

## Mathematical Topics Covered

- **Algebra**
- **Linear Algebra**
- **Calculus**
- **Vector Calculus**
- **Calculus of Several Variables**
- **Differential Equations**
- **Partial Differential Equations**
- **Probability and Statistics**

Each topic is organised into its own folder and contains pdf documents.

---

## Sources of the Exercises

The exercises were compiled from problem sets and exams from the following Chilean universities:

- Universidad de Chile  
- Universidad Técnica Federico Santa María  
- Universidad de Santiago de Chile  
- Pontificia Universidad Católica de Chile
